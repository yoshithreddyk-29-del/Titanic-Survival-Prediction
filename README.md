# Titanic Survival Prediction

## Machine Learning + Deep Learning Project

This project predicts whether a Titanic passenger survived using Machine Learning and Deep Learning.

## Models Used

### Machine Learning
- Logistic Regression
- Decision Tree
- Random Forest
- Gradient Boosting
- XGBoost

### Deep Learning
- Artificial Neural Network (ANN)
- 1D Convolutional Neural Network (1D CNN)

## Features

The Streamlit application accepts:

- Passenger Class
- Sex
- Age
- Siblings / Spouses
- Parents / Children
- Fare
- Port of Embarkation

## Evaluation Metrics

Models are compared using:

- Accuracy
- Precision
- Recall
- F1 Score
- ROC-AUC
